## 题目 1：简单查询（WHERE + 排序）

**查询计算机系所有女生的姓名和年龄，按年龄降序排列。**

```SQL
SELECT sname,age FROM student
WHERE sex = '女'
ORDER BY DESE
```

SELECT sname, age
FROM student
WHERE dept = '计算机' AND sex = '女'

## 题目 2：多表连接（INNER JOIN）

**查询所有选课学生的姓名、课程名和成绩。**

```sql
SELECT student.sname,course.cname,sc.score
FROM sc
JOIN student ON sc.sid = student.sid
JOIN course ON course.cid = sc.cid
```

```sql
SELECT s.sname, c.cname, sc.score
FROM student s
INNER JOIN sc ON s.sid = sc.sid
INNER JOIN course c ON sc.cid = c.cid;
```

## 题目 3：分组统计（GROUP BY + 聚合函数）

**查询每门课程的平均成绩，显示课程名和平均分，按平均分降序排列。**

```SQL
SELECT c.cname, AVG(sc.score)
FROM sc
JOIN course c ON c.cid = sc.cid
GROUP BY sc.sid
ORDER BY AVG(sc.score) DESC
```

```sql
SELECT c.cname, AVG(sc.score) AS avg_score
FROM course c
INNER JOIN sc ON c.cid = sc.cid
GROUP BY c.cid, c.cname
ORDER BY avg_score DESC;
```
